# Rock Paper Scissors 🎮

A browser-based Rock Paper Scissors game where the player competes against the computer. Choose Rock, Paper, or Scissors, see the result instantly, and keep track of the score.

## Features

* Three interactive choices: Rock, Paper, and Scissors.
* Computer generates a random choice.
* Displays the result of each round.
* Tracks the player's and computer's scores.
* Simple interface with visual icons and result messages.

## Built With

* HTML
* CSS
* JavaScript

## How to Play

1. Open the game in your browser.
2. Select Rock, Paper, or Scissors.
3. The computer makes its choice.
4. The game displays who wins the round.
5. Continue playing and compare the scores.

## Project Structure

* `index.html` — Game structure
* `style.css` — Styling and layout
* `app.js` — Game logic and score tracking
